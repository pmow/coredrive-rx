# CoreDrive RX v1.4.0

## What's new

- **Optional audio ping when a node is mapped.** A short "bloop" plays on every mapped
  reception, so you get feedback without looking at the phone: **silence** in a stale,
  device-free area, **frequent pings** where the mesh is active, and an audible sign that
  **capture is still alive**. Turn it on under **⚙️ Settings → Capture → "Sound ping when a
  node is mapped"**. **Off by default**, and your choice is **remembered across app starts**.
  No sound file is shipped — the tone is synthesised with Web Audio.

## Bug fixes

- **A drive no longer goes silent after you stop.** When capture auto-paused after ~5 min
  stationary, it resumed **only** on a fresh GPS fix. On a backgrounded / screen-off phone
  those GPS updates stall, so if you drove off again the rest of the drive could log
  **nothing** until you re-opened the app — a whole drive lost. Now a **heard packet also
  wakes capture**: the first packet from a moved position resumes logging even when GPS
  callbacks have stalled. (This was never a network issue — everything captured still
  uploaded; the missing points were simply never recorded.)

## Upgrade notes

- Service-worker cache bumped to `coredrive-rx-v12` — **hard-refresh / restart the PWA** to pick up the new assets.
- No config or data migration.
- The new sound cue is **off by default**; enable it in Settings if you want it.
