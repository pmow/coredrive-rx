# CoreDrive RX v1.9.1

- **A repeater that does not answer is now backed off** (5 / 15 / 30 min by attempt)
  instead of being asked every minute. Demotion alone was not enough: once every other
  candidate had answered, the silent one was handed back every round — observed as nine
  asks to one node in nine minutes. That is not just wasted airtime; `simple_repeater`
  rate-limits anonymous requests to 4 per 180 s shared across all types and requesters, so
  hammering a node makes it *less* likely to ever answer.
