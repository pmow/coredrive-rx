# CoreDrive RX v1.9.0

- **The standstill pause no longer silences region discovery.** The pause exists because
  re-sampling the same spot adds nothing to coverage — but a repeater's declared region
  list is a property of that repeater, not of where you are standing, and the repeaters
  that matter most are the ones you are parked next to. A parked app previously never
  asked at all.
