# CoreDrive RX v1.3.1

## What's new

- **Connect/Disconnect moved to Settings.** The button (with connection progress + status) leaves the
  Home screen, so the **recently-heard list moves up** — Home stays a pure monitor.
- **Opens on Settings until connected.** A fresh launch now lands on the **⚙️ Settings** tab (where
  Connect lives); on a successful connect the app **jumps to Home** so the live monitor is shown only
  when there's something to watch.
- **Last reception by name.** The last-reception line shows the resolved node **name** when available,
  upgrading from the raw ID once name resolution returns.

## Upgrade notes

- Service-worker cache bumped to `coredrive-rx-v9` — **hard-refresh / restart the PWA** to pick up the new assets.
- No config or data migration.
