# CoreDrive RX v1.3.2

## Bug fixes

- **CoreScope uploads no longer get permanently stuck.** After the v1.3.x update, a single
  transient MQTT drop could leave the broker **disconnected** with **every reception stuck
  pending** for the rest of the drive. Cause: the keepalive had been lowered to 20 s (exercising
  the reconnect path more often) while an unhandled `error` event could wedge mqtt.js's
  auto-reconnect loop. Fixed by restoring the default keepalive, attaching a **persistent error
  handler** so a transient error can never wedge the reconnect, and **logging every broker
  state change** (connect / reconnect / offline / close / error) to the debug log so any future
  drop is diagnosable.
- **Manual recovery.** *Settings → Push pending now* now **forces a reconnect** when the link is
  down, instead of doing nothing — so you're never stuck with a dead link and a full queue.
- The Home **upload dot turns red** on a real disconnect (previously the same idle grey).

## Upgrade notes

- Service-worker cache bumped to `coredrive-rx-v10` — **hard-refresh / restart the PWA** to pick up the new assets.
- No config or data migration.
