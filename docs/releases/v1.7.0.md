# CoreDrive RX v1.7.0

## What's new

- **The last 5 declared scopes are shown on Home**, and the top stats card was shrunk to
  make room.
- **Node-discover responses now count as region-discovery candidates.** With 47-hour
  advert intervals, real adverts are rare; the discover sweep is what actually finds
  repeaters, so waiting for an advert meant waiting most of a drive.
