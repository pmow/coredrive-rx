# CoreDrive RX v1.3.0

## What's new

- **Home is now a live monitor.** Session counters (**distinct nodes · hex cells covered · total
  receptions**), a compact status strip (**GPS accuracy in metres**, pending uploads, an **upload-health
  dot + last-upload age**, and a rolling **capture rate**), plus a **last-reception SNR meter** with a
  peak-hold marker so you can see at a glance when you're in good range of a node.
- **New ⚙️ Settings tab.** CoreScope **broker status + a "Push pending now"** button, companion info
  (name / pubkey / path-hash mode), and diagnostics (verbose toggle, debug log, and **Share / mail the
  debug log** — uses the Web Share API to attach the log as a `.txt`, with download/mailto fallbacks).
- **Discover runs automatically.** No more button — while connected the app sends a zero-hop
  node-discover request on its own, and **backs off for 15 s whenever organic traffic is overheard**
  (no point polling a busy channel). It's still suspended while stationary. A small status line shows
  *active* vs *backoff*.
- **Flood probe removed.** It propagated mesh-wide and added little for roaming coverage capture.

## Bug fixes

- **Uploads no longer get stuck (+60 pending on WiFi).** On a cellular→WiFi handoff the MQTT socket
  could die silently while still reporting "connected", so a publish hung forever and the drain loop
  stopped re-arming. Publishes now **time out** instead of hanging, the drain loop **always reschedules**,
  MQTT keepalive is lowered to detect a dead socket fast, and a drain is kicked on reconnect / when the
  network returns.

## Upgrade notes

- Service-worker cache bumped to `coredrive-rx-v8` — **hard-refresh / restart the PWA** to pick up the new assets.
- No config or data migration; the MQTT payload contract is unchanged.
