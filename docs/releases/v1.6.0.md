# CoreDrive RX v1.6.0

## What's new

- **Region discovery (opt-in, `regionDiscovery`).** The app can ask a repeater which
  flood-allowed regions it declares, and publishes the answer on
  `meshcore/client/<pubkey>/regions`. This is the **only** part of the app that transmits:
  one repeater at a time, round-robin, at most once every 60 seconds, zero-hop. Requires
  companion firmware **v13+**; on older firmware it logs why and never sends.
- Replies are matched by the echoed request tag rather than "something is pending", so one
  repeater's declared regions can never be attributed to a different repeater and stored
  as fact.
- The CSV truncation boundary is measured in wire bytes rather than code units, so an
  overflowing region list is flagged correctly.
